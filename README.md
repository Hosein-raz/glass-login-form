## 📖 About The Project

The **Glassmorphism Login Form** is a highly aesthetic, modern user interface component built purely with HTML and CSS. It fully embraces the popular Glassmorphism design trend, featuring a frosted glass form overlay, vibrant ambient background blobs, and smoothly animated floating elements. This project demonstrates how to create deep, engaging UI designs without writing a single line of JavaScript.

## ✨ Key Technical Features

This project highlights several advanced CSS properties and animation techniques:

* **Authentic Glassmorphism:** Utilizes `backdrop-filter: blur(10px)` alongside semi-transparent `rgba` backgrounds and subtle white borders to create a realistic frosted glass material for the form container and floating boxes.
* **Ambient Background Blobs:** Generates organic, glowing background shapes using absolute positioning and heavy CSS filtering (`filter: blur(150px)`).
* **Continuous Floating Animations:** The decorative mini-boxes float seamlessly using CSS `@keyframes` (`translateY`).
* **Staggered Animation Delays:** Cleverly uses custom CSS properties (like `--i:1`) injected inline to calculate offset `animation-delay` values dynamically, giving each floating box a unique, organic movement rhythm.

## 🚀 How to Use

You can easily integrate this stunning login form into your own web projects:

1. Clone the repository:
```bash
git clone https://github.com/Hosein-raz/glass-login-form.git
```
2. Copy the HTML structure from `index.html` (specifically the `<section>` and its contents).
3. Import the styles from `style.css` into your project's stylesheet to bring the glass effect and animations to life.

## 📂 Project Structure

```
glass-login-form/
├── index.html    # Contains the form structure and inline CSS variables for animations
└── style.css     # Contains the Glassmorphism styling, ambient blobs, and keyframes
```
